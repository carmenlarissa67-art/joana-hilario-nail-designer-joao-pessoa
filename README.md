# Joana Hilario Nail Designer

Site com agendamento online da Joana Hilario Nail Designer (Alto do Céu, João Pessoa).

- Todos os dados da cliente ficam em `src/data/studioData.js` (serviços, valores, horários, WhatsApp, Calendly).
- Os valores atuais são estimativa para a demo. Trocar pelos valores reais antes da entrega.
- `npm install` e `npm run dev` para rodar local. `npm run build` gera a pasta `dist`.
